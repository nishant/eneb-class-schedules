# ENEB Class Schedules

Weekly **Monday–Friday** timetables for the UMD Cyber-Physical Systems Engineering (ENEB)
cohorts, built from the live [Testudo Schedule of Classes](https://app.testudo.umd.edu/soc/).
Each class shows its time, room, and **professor**.

## 👉 Just want to see the schedule?

**Open this link — nothing to install:**

### https://nishant.github.io/eneb-class-schedules/

You'll get an overview page with two buttons:

- **Junior Cohort** (Semester 1)
- **Senior Cohort** (Semester 3)

Click either one to see that cohort's full Mon–Fri week. Works on phones and computers,
and you can print it (File → Print).

## For maintainers

The site in [`docs/`](./docs) is generated by a small scraper. You only need this if you
want to regenerate it (e.g. for a new semester).

### Refresh without a terminal
Go to the repo's **Actions** tab → **Refresh schedules** → **Run workflow**. It re-scrapes
Testudo and updates the site. It also runs automatically on the 1st of each month.

### Refresh on your computer
Requires [Node.js](https://nodejs.org) (v18+).

```bash
npm install
npm start           # regenerates docs/index.html, docs/junior.html, docs/senior.html
npm test            # parsing unit tests
npm run typecheck   # tsc --noEmit
```

Preview locally: `node serve.mjs` → http://localhost:4599

### Change term or courses
Edit **[`src/config.ts`](./src/config.ts)** only:

- `TERM` — Testudo term id, `<year><month>` (01 Spring · 05 Summer · 08 Fall · 12 Winter).
- `COHORTS[].courseIds` — the courses on each cohort's calendar.

### How it works / gotchas
- **Titles** come from `/soc/search` (which only returns rows when sent a browser
  `User-Agent`, so `src/fetch.ts` sets one); **section details** come from
  `/soc/<TERM>/sections`.
- Testudo emits a class type only for non-lecture meetings — an absent type means Lecture.
- Online meetings keep their day/time and show room "Online".
- `ENGL3XX "Professional Writing"` (a senior requirement) is **not** an ENEB course and has
  no scrapeable section, so it is intentionally left off the senior calendar.
