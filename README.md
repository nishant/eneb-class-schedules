# ENEB Class Schedules

Weekly **Monday–Friday** timetables for the UMD Cyber-Physical Systems Engineering (ENEB)
cohorts, built from the live [Testudo Schedule of Classes](https://app.testudo.umd.edu/soc/).
Each class shows its time, room, and **professor**.

## 👉 Just want to see the schedule?

**Open this link — nothing to install:**

### https://nishant.github.io/eneb-class-schedules/

You'll get an overview page with two buttons:

- **Junior Cohort** (Semester 1)
- **Senior Cohort** (Semester 3)

Click either one to see that cohort's full Mon–Fri week. Works on phones and computers,
and you can print it (File → Print).

## For maintainers

The site in [`docs/`](./docs) is generated by a small scraper. You only need this if you
want to regenerate it (e.g. for a new semester).

### Run it on your computer

Everything runs locally — the scraper fetches from Testudo and writes plain HTML files.
There's no database and nothing to deploy.

**1. Install Node.js** (one-time)

Download the LTS installer from **https://nodejs.org** and run it (accept the defaults).
This gives you both `node` and `npm`. To confirm it worked, open a terminal
(PowerShell on Windows, Terminal on macOS) and run:

```bash
node --version    # should print v18 or higher
```

**2. Get the code** (one-time)

Either clone with git:

```bash
git clone https://github.com/nishant/eneb-class-schedules.git
cd eneb-class-schedules
```

…or, if you don't use git, download the ZIP from the GitHub page
(green **Code** button → **Download ZIP**), unzip it, and `cd` into the folder.

**3. Install the dependencies** (one-time, and after any `git pull`)

```bash
npm install
```

**4. Generate the schedules**

```bash
npm start
```

This scrapes Testudo and writes three files into [`docs/`](./docs): `index.html` (the
overview), `junior.html`, and `senior.html`. You'll see a summary like:

```
  ✓ Junior Cohort: 5 sections, 9 meetings → …/docs/junior.html
  ✓ Senior Cohort: 4 sections, 7 meetings → …/docs/senior.html
  ✓ Overview page → …/docs/index.html
```

**5. View the schedules**

Just open `docs/index.html` in your browser — double-click it, or from the terminal:

```bash
# Windows
start docs\index.html
# macOS
open docs/index.html
```

Or run the tiny built-in preview server (auto-refreshes as you regenerate):

```bash
node serve.mjs      # then visit http://localhost:4599
```

**(Optional) checks**

```bash
npm test            # parsing unit tests
npm run typecheck   # TypeScript type-check (tsc --noEmit)
```

**Publish your changes** (optional) — if you want the live site to update, commit and push:

```bash
git add docs
git commit -m "Refresh schedules"
git push
```

### Change the term or courses

Edit **[`src/config.ts`](./src/config.ts)** only, then re-run `npm start` (step 4 above):

- `TERM` — Testudo term id, `<year><month>` (01 Spring · 05 Summer · 08 Fall · 12 Winter).
- `COHORTS[].courseIds` — the courses on each cohort's calendar.

### Refresh without a terminal

Prefer not to touch the command line at all? Go to the repo's **Actions** tab →
**Refresh schedules** → **Run workflow**. It re-scrapes Testudo and updates the site.
It also runs automatically on the 1st of each month.

### How it works / gotchas
- **Titles** come from `/soc/search` (which only returns rows when sent a browser
  `User-Agent`, so `src/fetch.ts` sets one); **section details** come from
  `/soc/<TERM>/sections`.
- Testudo emits a class type only for non-lecture meetings — an absent type means Lecture.
- Online meetings keep their day/time and show room "Online".
- `ENGL3XX "Professional Writing"` (a senior requirement) is **not** an ENEB course and has
  no scrapeable section, so it is intentionally left off the senior calendar.
